We found that increasing the maximum node degree beyond a certain point has beneficial effects in some ranges, as shown in the figure~\ref{fig:latency-vs-max-deg}, the latency of message delivery per communication radius generally increases in correlation with the maximum constrained node degree.
The different communication radii are shown as distinct curves on the plot, which indicates, as we expected, a trend towards a lower latency with a lower communication radius.
A lower communication radius in turn creates fewer messages, as there are generally fewer links and peers to propagate messages to, which exhibits less strain on the message buffers of the individual hosts.
An important insight that we derive from this plot is that increasing the maximum node degree beyond a certain point does not significantly improve the latency of message delivery, and that increase is echoed in longer communication ranges: in other words, the further the communication range, the less effect an increase in maximum node degree has on the latency of message delivery.
Surprisingly, higher communication ranges exhibit a positive effect on latency with an increase in maximum node degree.
This phenomenon is especially visible in the 100m communication radius.
